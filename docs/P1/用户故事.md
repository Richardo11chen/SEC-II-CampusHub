# 用户故事

**US01：用户注册**

**作为** 一名南大学生，

**我希望** 使用学号进行注册和登录，

**以便** 证明我的在校身份，防止校外人员进入平台。

**验收标准：**

1. 用户输入学号和密码即可完成注册
2. 系统验证学号真实性（对接学校认证或人工审核）
3. 同一学号只能注册一个账号
4. 密码需加密存储

**优先级：Must**

**US02：个人资料管理**

**作为** 一名注册用户，

**我希望** 可以编辑我的个人资料（头像、昵称、学院、联系方式），

**以便** 让其他同学更好地了解我，建立信任。

**验收标准：**

1. 用户可以修改头像、昵称、学院、联系方式
2. 修改后实时保存并展示
3. 昵称不能为空，长度2-20字符
4. 联系方式可选择是否公开

**优先级：Must**

**US03：匿名发布需求**

**作为** 一名注重隐私的学生，

**我希望** 发布需求时可以选择匿名，

**以便** 在不暴露真实姓名的情况下获得帮助。

**验收标准：**

1. 发布表单中有“匿名发布”复选框
2. 匿名发布的需求在列表中只显示昵称，不显示真实姓名
3. 服务方接单后可见需求方真实信息
4. 匿名发布者的真实信息仅对平台和服务方可见

**优先级：Should**

**US04：发布互助需求**

**作为** 一名有需要的学生，

**我希望** 可以发布包含标题、描述、分类、地点、时间和报酬的互助需求，

**以便** 清晰地向他人说明我需要什么帮助。

**验收标准：**

1. 发布表单包含：标题、描述、分类（下拉选择）、地点、期望完成时间、报酬
2. 报酬可以为0，表示无偿互助
3. 所有字段不能为空（报酬可以为0）
4. 发布后需求出现在需求列表中

**优先级：Must**

**US05：需求分类筛选**

**作为** 一名浏览需求的学生，

**我希望** 可以按分类（快递代取、二手交易、失物招领等）筛选需求，

**以便** 快速找到我感兴趣或能帮忙的事情。

**验收标准：**

1. 需求列表顶部有分类筛选标签
2. 点击分类后只显示该分类下的需求
3. 支持“全部”分类恢复显示所有需求
4. 分类包括：快递代取、学习辅导、二手交易、活动组队、失物招领、拼车拼单、找搭子、咨询答疑、其他

**优先级：Must**

**US06：紧急需求置顶**

**作为** 一名有紧急事务的学生，

**我希望** 可以将我的需求标记为“紧急”并置顶展示，

**以便** 更快地获得他人关注和响应。

**验收标准：**

1. 发布需求时可选择“紧急”标记
2. 紧急需求在列表中置顶显示
3. 紧急需求带有红色“紧急”标识
4. 同一用户同时只能有1个紧急需求

**优先级：Should**

**US07：接单**

**作为** 一名愿意帮助他人的学生，

**我希望** 可以点击“接单”按钮承接一个进行中的需求，

**以便** 为有需要的同学提供帮助并获得报酬或信用分。

**验收标准：**

1. 需求详情页有“接单”按钮
2. 用户不能接自己发布的需求
3. 一个需求只能被一个人接单
4. 接单后需求方收到通知
5. 信用分低于40分的用户不能接单

**优先级：Must**

**US08：确认完成**

**作为** 一名需求方，

**我希望** 在服务方完成任务后确认完成，

**以便** 释放报酬并完成订单流程。

**验收标准：**

1. 服务方标记“已完成”后，需求方收到通知
2. 需求方有48小时确认期
3. 需求方点击“确认完成”后订单状态变更为“已完成”
4. 超时未确认则系统自动确认完成
5. 确认后报酬打给服务方

**优先级：Must**

**US09：拒绝完成与纠纷申诉**

**作为** 一名需求方，

**我希望** 如果服务方没有按约定完成任务，我可以拒绝完成并发起申诉，

**以便** 在出现分歧时获得平台公正的处理。

**验收标准：**

1. 需求方点击“拒绝完成”时可填写原因
2. 拒绝后订单进入纠纷处理状态
3. 双方可上传凭证（文字、图片）
4. 管理员可查看聊天记录和凭证并做出裁决

**优先级：Should**

**US10：双向评价**

**作为** 一名完成订单的用户，

**我希望** 可以对对方进行1-5星评分和文字评价，

**以便** 帮助其他用户了解对方的可靠程度。

**验收标准：**

1. 订单完成后双方进入评价页面
2. 评价包含1-5星评分和文字评价（可选）
3. 评价后双方信用分相应调整
4. 评价内容在对方主页展示

**优先级：Must**

**US11：查看信用分**

**作为** 一名寻找帮助的学生，

**我希望** 可以看到服务方的信用分和历史评价，

**以便** 判断对方是否可靠，决定是否把任务交给他。

**验收标准：**

1. 用户主页展示信用分（0-100）
2. 信用分下方展示最近10条评价内容
3. 需求列表和详情页显示发布者的信用分
4. 信用分低于40分的用户禁止发布需求

**优先级：Must**

**US12：爽约扣分**

**作为** 一名守信用的学生，

**我希望** 平台对爽约行为进行扣分处理，

**以便** 让不守信用的用户受到惩罚，维护平台信任环境。

**验收标准：**

1. 接单后无故取消扣5分
2. 接单后未完成任务扣10分
3. 30天内累计爽约≥3次，自动限制接单15天
4. 用户可查看自己的扣分记录

**优先级：Should**

**US13：站内通知**

**作为** 一名用户，

**我希望** 在有人接单、订单状态变更、收到评价时收到站内消息通知，

**以便** 及时了解订单进展。

**验收标准：**

1. 用户收到通知时顶部消息图标有红点提示
2. 点击图标显示通知列表
3. 通知包含：接单通知、状态变更通知、评价通知
4. 未读通知与已读通知有视觉区分

**优先级：Should**

**US14：订单内私信**

**作为** 一名已接单的用户，

**我希望** 可以在订单内与对方进行一对一私信（支持文字和图片），

**以便** 沟通任务细节，不需要跳转到微信。

**验收标准：**

1. 订单详情页有聊天入口
2. 支持发送文字消息
3. 支持发送图片（P2可选）
4. 聊天记录保存供纠纷时查阅

**优先级：Could**

**US15：过期需求清理**

**作为** 一名浏览需求的学生，

**我希望** 过期的需求能够自动被清理或隐藏，

**以便** 不看到已经无效的信息。

**验收标准：**

1. 超过30天未完成且无互动（无人接单/无更新）的需求自动归档/删除
2. 用户可手动删除自己的过期需求
3. 过期需求不再出现在列表中
4. 用户可在“我的发布”中查看已归档的需求

**优先级：Should**

**US16：内容审核（管理员）**

**作为** 一名平台管理员，

**我希望** 可以查看和删除违规需求，

**以便** 维护平台的内容安全。

**验收标准：**

1. 后台有需求审核列表
2. 管理员可查看需求详情
3. 管理员可删除违规需求并通知发布者
4. 删除操作需二次确认

**优先级：Could**

**US17：志愿管理员申请**

**作为** 一名热心学生，

**我希望** 可以申请成为志愿管理员，

**以便** 帮助平台进行内容审核和纠纷处理。

**验收标准：**

1. 用户可提交志愿管理员申请（填写申请理由）
2. 管理员可审批申请
3. 审批通过后用户获得部分管理权限
4. 志愿管理员无经济报酬，可获得信用分奖励

**优先级：Could**
