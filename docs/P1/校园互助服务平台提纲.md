# 校园互助服务平台（CampusHub）用户访谈提纲

- **··访谈开场白**

同学你好！感谢你抽出时间参与这次访谈。我们正在做一个校园互助服务平台的项目，希望了解大家在校园里找人帮忙的真实经历和想法。你的回答没有对错之分，我们会严格保密，仅用于需求分析。

**访谈问题**

1. 回忆一下，最近一次你找人帮忙（或帮别人）是做什么事情？当时是怎么找到对方的？
2. 你觉得现在用的这些方式（比如微信群、朋友圈、QQ群等）有哪些让你觉得不方便或不舒服的地方？
3. 如果一个校园互助平台上线，你觉得什么功能或特点会让你愿意使用它？什么情况会让你不想用？
4. 在找人帮忙时，你通常最在意什么？比如响应速度、对方是否可靠、报酬高低、还是其他？为什么？
5. 如果平台引入了信用分和评价体系（类似闲鱼或滴滴），你会在意自己的信用分吗？你希望信用分如何影响你的使用体验？*？*
6. 如果任务完成过程中出现了分歧（比如你觉得完成了，对方觉得没完成），你希望平台怎么处理？你对平台介入的边界有什么期望？

**访谈结束语**

好的，我的问题问完了。非常感谢你的分享！如果你后续还有任何想法，随时可以补充。再次感谢！
