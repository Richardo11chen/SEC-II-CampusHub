## 第一阶段：基础架构与用户核心（P0）

**目标：** 完成项目骨架搭建、用户注册登录认证体系。

| 任务ID | 任务描述 | 负责人 | 优先级 | 完成标准 | 预计 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| T01 | **[后端]** 搭建项目骨架，配置 MySQL+Prisma，定义 User 模型 | 后端A | P0 | Prisma `npx prisma db push` 成功；User 表含 student_id/password_hash/nickname/credit_score/role 等核心字段 | 3h |
| T02 | **[后端]** 实现用户注册接口（F01, F05）| 后端B | P0 | `POST /api/auth/register` 可用；学号10位数字校验；密码 bcrypt 加密入库；student_id 唯一冲突返回 409；成功返回 201 | 3h |
| T03 | **[后端]** 实现用户登录接口，生成 JWT（F01）| 后端B | P0 | `POST /api/auth/login` 可用；学号/密码错误返回 401；成功返回 token+refreshToken+user 信息；实现 JWT 验证中间件 | 3h |
| T04 | **[后端]** 实现 Token 刷新与登出接口 | 后端B | P0 | `POST /api/auth/refresh` 轮换 Token 对；`POST /api/auth/logout` 标记 refresh_token 失效 | 2h |
| T05 | **[前端]** 搭建前端项目（React+Vite），配置路由守卫、axios 拦截器 | 前端A | P0 | 基础路由（首页、登录、注册）可访问；axios 拦截器自动附加 `Authorization: Bearer` 头；未登录自动跳转登录页 | 3h |
| T06 | **[前端]** 开发注册页面，对接 T02 注册接口 | 前端A | P0 | 表单含学号/密码/昵称字段；学号格式前端校验；注册成功后自动跳转登录页；失败展示后端错误信息 | 2h |
| T07 | **[前端]** 开发登录页面，对接 T03 登录接口 | 前端A | P0 | 表单含学号/密码字段；登录成功后存储 token/refreshToken 并跳转首页；失败展示错误提示 | 2h |
| T08 | **[后端]** 实现个人资料查看与更新接口（F02, F04）| 后端B | **P0** | `GET/PUT /api/users/me` 可用；PUT 支持 nickname/avatar/college/phone/showRealName；手机号 AES-256 加密存储；响应脱敏展示 | 3h |
| T09 | **[前端]** 开发个人资料页面，对接 T08 接口 | 前端A | **P0** | 展示个人信息（脱敏手机号）；可编辑昵称/头像/学院/真实姓名展示开关；修改后即时刷新 | 3h |

## 第二阶段：需求发布与浏览（P0）

**目标：** 用户能发布、查看和筛选互助需求。

| 任务ID | 任务描述 | 负责人 | 优先级 | 完成标准 | 预计 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| T10 | **[后端]** 在 Prisma 中添加 Demand、DemandImage 模型并迁移 | 后端A | P0 | `npx prisma db push` 成功；Demand 表含 title/description/category/reward/status/version 等字段；含乐观锁 version 字段 | 1h |
| T11 | **[后端]** 实现需求发布接口（F06, F07）| 后端A | P0 | `POST /api/demands` 可用；校验 title/description/category 必填；校验 reward ≥ 0；`credit_score < 40` 返回 403；成功返回 201 | 3h |
| T12 | **[后端]** 实现需求列表接口，支持筛选分页排序（F08）| 后端A | P0 | `GET /api/demands` 可用；支持 category/status/keyword/sortBy/page/pageSize 参数；keyword 走全文索引；返回 `items + pagination` | 4h |
| T13 | **[后端]** 实现需求详情接口（F09）| 后端A | P0 | `GET /api/demands/{demandId}` 可用；返回需求全部字段+发布者 DTO（不含敏感信息）；匿名发布时隐藏发布者信息 | 2h |
| T14 | **[前端]** 开发需求发布页面 | 前端A | P0 | 表单含标题/描述/分类下拉/地点/预期时间/报酬/图片上传；分类下拉枚举值与后端一致；表单校验；成功跳转详情页 | 3h |
| T15 | **[前端]** 开发需求广场页面，实现列表展示与筛选 | 前端B | P0 | 需求卡片列表展示（标题/分类/报酬/状态/发布时间）；分类筛选器；排序切换（最新/报酬高-低）；分页控件；搜索框 | 4h |
| T16 | **[前端]** 开发需求详情页 | 前端A | P0 | 展示需求完整信息+发布者信息；显示匿名/紧急标签；图片画廊展示 | 2h |
| T17 | **[后端]** 实现文件上传接口 | 后端B | P0 | `POST /api/upload` 可用；图片大小限制 10MB；返回图片 URL；限制文件类型为常见图片格式 | 2h |

## 第三阶段：订单流程与评价体系（P0 & P1）

**目标：** 完成接单到确认的完整流程，建立信用评价机制。

| 任务ID | 任务描述 | 负责人 | 优先级 | 完成标准 | 预计 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| T18 | **[后端]** 在 Prisma 中添加 Order、Review 模型并迁移 | 后端A | P0 | Order 表含 demand_id(UK)/publisher_id/provider_id/status/reward/version；Review 表含 `UNIQUE(order_id,from_user_id)` | 1h |
| T19 | **[后端]** 实现接单接口（F12, F13）| 后端A | P0 | `POST /api/orders` 可用；乐观锁防止并发抢单（version 校验），冲突返回 409；成功后 Demand.status → "进行中" | 3h |
| T20 | **[后端]** 实现提交完成与确认完成接口（F14）| 后端A | P0 | `PUT /api/orders/{orderId}/complete` 服务方提交→状态变"待确认"；`PUT /api/orders/{orderId}/confirm` 需求方确认→状态变"已完成"；48h 自动确认逻辑（定时任务） | 3h |
| T21 | **[后端]** 实现订单取消与订单列表/详情接口（F14, F17）| 后端A | P0 | `PUT /api/orders/{orderId}/cancel` 取消订单；`GET /api/orders` 支持 role/status/page 参数；`GET /api/orders/{orderId}` 返回双方信息+需求信息；非参与方返回 403 | 4h |
| T22 | **[前端]** 在需求详情页添加"接单"按钮 | 前端B | P0 | 仅需求状态为"开放"且当前用户非发布者时显示；接单成功弹窗提示+按钮禁用；408 冲突展示"已被接走" | 2h |
| T23 | **[前端]** 开发"我的订单"页面 | 前端B | P0 | 区分"我发布的"和"我承接的"Tab；按状态筛选（进行中/待确认/已完成/已取消）；展示订单卡片（需求标题/状态/报酬/对方昵称） | 3h |
| T24 | **[前端]** 开发订单详情页 | 前端B | P0 | 展示需求信息+双方信息+订单状态流转；服务方视角可"提交完成"；需求方视角可"确认完成"；状态变更后 UI 即时刷新 | 3h |
| T25 | **[后端]** 实现评价接口与信用分计算（F18, F19）| 后端B | **P1** | `POST /api/reviews` 可用；仅已完成订单可评价；同一订单同一用户不可重复评价（409）；按规则更新信用分（5星+3, 4星+1, 1-2星-5） | 3h |
| T26 | **[后端]** 实现用户公开资料接口（F20）| 后端B | P1 | `GET /api/users/{userId}/profile` 可用；返回信用分/评价统计/订单数；`GET /api/users/{userId}/reviews` 分页返回评价列表 | 2h |
| T27 | **[前端]** 在已完成订单中添加评价入口与评价表单 | 前端B | P1 | 1-5 星评分组件；文字评价输入框（最多 1000 字）；提交后 UI 展示已评价状态 | 3h |
| T28 | **[前端]** 开发用户公开主页 | 前端A | P1 | 展示用户信用分/评价统计/历史评价列表；从 T12 跳转到用户主页 | 2h |
